---------

LIKE 
-----
>> pattern matching.

Ex: .... col LIKE pattern;

patterns or wildcard 
-----------------------
% --> matches 0 to inf number of char.
_ --> matches only 1.

starts with v --> "v%" --> "Vinutha", "vijay"
ends with a --> "%a" --> "anitha", "a", "vijay"
contains a --> "%a%" --> "vijay"

"____a" --> "arya", "surya"

Query 
------
To Create a Database ---> CREATE DATABASE dbName;
To Select a DB ---> USE dtabaseName;
To Create a Table ---> CREATE TABLE tbname (
    col1 dt constraints,
    col2 dt constraints,
    .
    .
);
To create records --> INSERT INTO tbname (col details) VALUES (),()....;
To Retrive data from a table --> SELECT (col details (*)) FROM tbname;
To Update a record --> UPDATE tbname SET col=val;
To Delete a record --> DELETE FROM tbname;
