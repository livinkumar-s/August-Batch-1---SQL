Joins 
---------
It combines data from two or more tables based on related column.

Inner Join 
-----------
>> It retrives only the matchiong rows from both tables.
Ex: SELECT * FROM tb1 INNER JOIN tb2 ON (relation);

Left Outer Join 
-----------------
>> It retrives all rows from left table.
>> It retrives only the matching records from right table.
Ex: SELECT * FROM tb1 LEFT JOIN tb2 ON (relation);

Right Outer Join 
-----------------
>> It retrives all rows from right table.
>> It retrives only the matching records from left table.
Ex: SELECT * FROM tb1 RIGHT JOIN tb2 ON (relation);

Full outer Join 
----------------
>> It retrives all records from both tables
left join (union) right join.
